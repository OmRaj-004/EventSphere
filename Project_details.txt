KEY FEATURES IMPLEMENTED
========================

1. AUTHENTICATION & AUTHORIZATION
---------------------------------
- Three-role system: ADMIN, CUSTOMER, HOST (separate tables)
- BCrypt password hashing (cost 12)
- Session-based auth (30-min timeout, HttpOnly cookies)
- Session fixation protection (changeSessionId on login)
- Remember-me: SHA-256 hashed tokens, 30-day expiry
- Self-service password reset: email tokens (SHA-256, single-use, 1hr expiry)
- Rate limiting: 5 attempts/15 min per IP on /login, /register, /forgot, /reset
- CSRF tokens on all state-changing forms
- Role-based filters (Authentication, Admin, Customer, Host)
- Session fixation protection (changeSessionId on login)

2. VENUE MANAGEMENT
-------------------
- CRUD by admins and hosts
- Search: event type, location, capacity, price range
- Pagination (10/page)
- Photo upload + URL picker with gallery
- Availability calendar (2-month, booked dates from events)
- Status: AVAILABLE / MAINTENANCE / INACTIVE
- Host ownership with admin override

3. BOOKING ENGINE
-----------------
- Single + multi-venue bookings
- Live price estimate (hourly rate × duration, INR)
- Promo code validation (%, usage limits)
- Server-side validation: future date, start<end, guests≤capacity
- Overlap prevention: transactional check at booking + re-check at approval
- Status flow: PENDING → APPROVED/REJECTED/CANCELLED
- Booking edit (reschedule) with re-validation
- Cancellation (customer for PENDING, admin anytime)

4. BILLING & INVOICING
----------------------
- One bill per booking (atomic creation with booking)
- Server-calculated total (rate × hours, promo discount)
- HTML bill + PDF generation (OpenPDF)
- Print-optimized layout (original PNG logo for print)
- Status: ISSUED / PAID / CANCELLED

5. FEEDBACK & RATINGS
---------------------
- Only for APPROVED bookings
- Rating 1-5 + comment + optional photo
- One review per booking (partial unique index)
- Average rating + count on venue cards/details
- Host replies (admin can moderate)

6. NOTIFICATIONS
----------------
- In-app bell icon with unread count
- Types: booking decision, feedback reply, system
- Role-scoped (ADMIN/CUSTOMER/HOST)
- Mark-as-read (single/all), unread counts

7. PROMO CODES
--------------
- Percentage discounts (1-90%)
- Usage limits (max_uses, used_count)
- Active/inactive toggle
- Validation at booking time

8. ADMIN ANALYTICS & REPORTS
----------------------------
- Booking stats by status
- Revenue summary (billed, outstanding, avg)
- Venue rankings by bookings/revenue
- Monthly booking trends
- Donut charts, horizontal bar charts

9. AUDIT LOGGING
----------------
- Every admin action logged: actor, action, target, detail, timestamp
- Queryable by actor, date, target type

10. SEARCH & FILTERS
--------------------
- AJAX venue search with skeleton loaders
- history.pushState for shareable URLs
- Graceful fallback to full navigation
- Skeleton cards during load

11. UI/UX ENHANCEMENTS
----------------------
- Styled confirm modal (replaces native confirm/alert)
- Toast notifications (success/error, auto-dismiss)
- Venue image lightbox (click enlarge, ESC/overlay close)
- Live price estimator on booking form
- Inline per-field validation with aria-invalid
- Skeleton loaders for AJAX operations
- Responsive (5 breakpoints: 1024, 900, 768, 640, 560)
- Skip-to-content, :focus-visible, prefers-reduced-motion
- Vector brand logo + SVG favicon (original PNG for print)

DATABASE DESIGN (13 Tables)
===========================

IDENTITY TABLES
---------------
admin_users (id, full_name, email UNIQUE, password_hash BCrypt, timestamps)
customer_users (same columns) - self-registered
host_users (same columns) - created by admins
All passwords: BCrypt cost 12 in password_hash

CATALOGUE TABLES
----------------
venues (id, name, description, location, event_type DEFAULT 'OTHER',
        max_capacity CHECK>0, hourly_rate CHECK>=0, amenities, image_url,
        available BOOL, status ENUM, created_by→admin_users, host_id→host_users, timestamps)
events (id, name, description, event_type, event_date, start_time, end_time,
        expected_guests, organizer_id, venue_id→venues SET NULL, status DEFAULT 'DRAFT', timestamps)

TRANSACTION TABLES
------------------
bookings (id, booking_number UNIQUE, event_id→events CASCADE, venue_id→venues CASCADE,
          customer_id→customer_users CASCADE, booking_date, total_amount, advance_paid,
          discount_amount, promo_id→promocodes SET NULL,
          status ENUM('PENDING','APPROVED','REJECTED','CANCELLED'),
          payment_method, transaction_id, notes, timestamps)

bills (id, bill_number UNIQUE, booking_id UNIQUE→bookings CASCADE,
       customer_id→customer_users CASCADE, subtotal, advance_paid, balance_due,
       status ENUM('ISSUED','PAID','CANCELLED'), created_at)

ENGAGEMENT TABLES
-----------------
feedback (id, booking_id→bookings SET NULL, customer_id→customer_users CASCADE,
          venue_id→venues CASCADE, rating CHECK 1-5, comment, image_url,
          admin_reply, created_at) - unique index (booking_id, customer_id)

notifications (id, user_id, user_role ENUM, title, body, link, is_read DEFAULT FALSE, created_at)

promocodes (code UNIQUE, percent_off CHECK 1-90, max_uses, used_count, active, created_at)

SECURITY IMPLEMENTATION
=======================
- BCrypt cost 12 password hashing (zero plaintext)
- SHA-256 for reset/remember tokens (single-use, expiry)
- Session fixation protection (changeSessionId on login)
- HttpOnly, 30-min sessions, Secure cookies in prod
- Identity always from session (never request params)
- Rate limiting: 5 req/15 min per IP on auth endpoints
- CSRF tokens on all state-changing POST forms
- Prepared statements everywhere (zero SQLi)
- Output escaping via EscapeUtil (XSS prevention)
- Rate limiting on auth endpoints (5/15min/IP)
- Destructive actions: POST + CSRF + confirm modal
- Audit logging for all admin actions
- Audit logging for all admin actions
